# 性能指标

## Lighthouse性能指标

### 首次内容绘制FCP

定义​​：首次绘制文本、图片等 DOM 内容的时间。
​​优化目标​​：≤1.8 秒。
​​权重​​：10%。

### 最大内容绘制LCP

定义​​：视口中最大内容元素（如图片、标题）渲染完成的时间。
​​优化目标​​：≤2.5 秒（移动端）。
​​权重​​：25%。
